┌──────────────────────────────────────────────────────────────────────────────┐
│                        RECONCILIATION LOGIC                                  │
└──────────────────────────────────────────────────────────────────────────────┘

Step 1: Merge Salary + TDS (by Employee ID)
   Salary[EmpCode] ←→ TDS[Employee Code]
   
Step 2: Merge with Bank SOA (by Employee ID)
   Result[EmpCode] ←→ Bank[EmpCode extracted from "Name-ID"]
   
Step 3: Merge with EPF (by UAN)
   Result[UAN] ←→ EPF[UAN]
   
Step 4: Compare Amounts
   ✓ Salary TDS vs TDS Amount
   ✓ Net Payable vs Bank Payment
   ✓ Salary EPF vs EPF Amount
   
Step 5: Flag Discrepancies
   If difference > ₹1.00 → Mark as Mismatch
   Otherwise → Mark as Matched
   
Step 6: Generate Remarks
   List all mismatches with actual differences

│                         DEPLOYMENT OPTIONS                                   │
└──────────────────────────────────────────────────────────────────────────────┘

Option 1: Systemd Service (Recommended for Linux Servers)
   sudo bash install_service.sh
   → Runs continuously in background
   → Auto-starts on boot
   → Managed by systemd

Option 2: Cron Job (Alternative for Linux)
   # Add to crontab
   0 9 16 * * /usr/bin/python3 /path/to/main.py --reminder
   0 10 17 * * /usr/bin/python3 /path/to/main.py --reconcile

Option 3: Windows Task Scheduler
   Create two scheduled tasks:
   - Task 1: Run on 16th at 9 AM
   - Task 2: Run on 17th at 10 AM

Option 4: Manual Execution
   python scheduler.py
   → Keep terminal open
   → Use screen/tmux for persistence
